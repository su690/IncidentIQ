# IncidentIQ
In modern banking and financial services, payment systems are built using multiple distributed microservices such as Payment, Fraud Detection, Customer, and Notification services, so when one service fails, the resulting problem can propagate across the entire transaction flow and make troubleshooting difficult. I built **Agentic SRE**, a local production-like incident investigation platform that simulates this environment and uses an AI agent with **Model Context Protocol (MCP)** to investigate failures like a real Site Reliability Engineer. The platform contains multiple Spring Boot microservices connected to PostgreSQL, with structured logging, correlation IDs, service-health monitoring, Prometheus metrics, and Grafana dashboards. I also created a controlled chaos layer that can intentionally introduce realistic production problems such as HTTP 503 failures, database outages, high latency, application exceptions, and faulty deployments. When an incident occurs—for example, the Fraud Service starts returning HTTP 503 responses and the Payment Service begins failing transactions—the AI agent receives the incident and autonomously investigates it by using MCP tools to check service health, search application logs, trace correlation IDs, inspect failed transactions in PostgreSQL, analyze metrics, examine recent Git commits, and compare the evidence across services. Instead of simply generating a guess, the agent builds an evidence-based investigation containing the affected service, severity, probable root cause, confidence level, supporting evidence, business impact, and recommended remediation. Potential remediation actions are placed behind a human-approval step so the agent cannot perform sensitive operations without authorization. The project therefore combines **Java, Spring Boot, Microservices, PostgreSQL, Spring AI, MCP, Agentic AI, REST APIs, Docker, Prometheus, Grafana, Git, observability, and human-in-the-loop automation** into a single end-to-end system designed to demonstrate how AI agents can assist engineers in diagnosing complex distributed-system incidents.
